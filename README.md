# Data Science for Human-Centered Systems

This repository contains my coursework and assignments for **Data Science for Human-Centered Systems**. The projects focus on applying data science methods to human-centered problems, including data cleaning, exploratory data analysis, statistical modeling, machine learning, visualization, and interpretation.

## Contents

- Jupyter notebooks for course assignments
- Datasets used for analysis
- Visualizations and model outputs
- Written interpretations and reflections

## Topics Covered

- Data cleaning and preprocessing
- Exploratory data analysis
- Linear regression
- Logistic regression
- Classification models
- Model evaluation
- Human-centered interpretation of data

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## Note

This repository is intended for academic and portfolio purposes. Some datasets or assignment materials may be excluded if they are course restricted
